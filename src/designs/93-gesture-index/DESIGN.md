# 93 Gesture Index

**Idea.** A drawn shape can be a precise invitation to an existing collection.

**Composition.** The browser is a drawing surface, not a page introducing one. An immense charcoal query crosses a faint dot field; retrieved objects appear as handwritten specimen slips near its ends. A compact form tray provides equivalent searches.

**Navigation and complete example.** Draw a line on the canvas or choose arch, zigzag, loop or branch. A small deterministic classifier retrieves original objects from a labelled fixture set; inspect records and save a constellation.

**Responsive and inclusive behaviour.** The phone begins with the drawing surface and its reachable form tray. Retrieved slips move beneath the canvas to preserve uninterrupted drawing and readable results. Native buttons, visible focus, a direct return path and reduced-motion support preserve access to the same content.

**Adaptation.** Keep the relationship between query shape and retrieved content legible. Explain the classifier’s limits instead of implying a general visual search engine. Retain the relationship between navigation and content. Do not reduce the reference to a generic hero followed by interchangeable cards.

**Research.** [Zach Lieberman / Data Arts Team — Land Lines](https://experiments.withgoogle.com/land-lines). These are conceptual precedents, not copied artwork, source code, branding or text. All diagrams and sample writing in this specimen are original, fictional material.
